# 小红书七日爆款笔记

为内容创作者与运营人员提供小红书七日爆款笔记：一键获取垂直领域热门榜单与深度分析。

## 数据规则

- **更新时间**：每日 19:00 更新昨日榜单（≥19:00 查昨日，<19:00 查前天，工具自动判断；用户指定日期直用）
- **数据范围**：往前 7 天热门笔记 TOP50
- **分类**：24 个垂直领域（综合全部/出行代步/休闲爱好/影视娱乐/数码科技/医疗保健/星座情感/时尚穿搭/婚庆婚礼/拍摄记录/学习教育/化妆美容/居家装修/旅行度假/亲子育儿/个人护理/美味佳肴/职业发展/宠物天地/潮流鞋包/日常生活/科学探索/新闻资讯/体育锻炼）
- **排序**：互动数优先（`anaAdd.interactiveCount`，支持 "2w+" 格式）；备用 = 点赞 + 收藏×2 + 评论×3 + 分享×5

## 鉴权

需要 RedFox API Key（`ak_` 开头，[红狐 hub](https://redfox.hk/settings/api-keys?source=github) 获取）。优先级：插件配置 > 面板「设置」页 > 环境变量 `REDFOX_API_KEY`。

## 工作流

### 第一步：分类匹配（v2.0 规则，强制）

`xhs_weekly(action="match", keyword="睫毛膏")`：

- **关键词命中分类**（最长关键词优先，如"旅游攻略"→旅行度假而非出行代步）→ 直接 fetch
- **未命中任何分类 → 禁止直接查询**：把工具返回的推荐分类（1~3 个，按相关度）展示给用户 + "⚠️若无想要查询的分类，可前往 https://redfox.hk/apis/xiaohongshu/384C6W6B?source=github API文档查询"，**等待用户确认**；用户选「若无」则停止全流程

### 第二步：拉取榜单

`xhs_weekly(action="fetch", category="化妆美容", topN=50)` —— 同步返回表格 TOP20 + 查看更多提示。工具自动：判断日期、按互动数排序、入库（同分类+同日期覆盖）。

### 第三步：三步输出（强制顺序，禁止折叠、禁止遗漏）

**① 🔥 七日爆款笔记（含更新时间）**：工具生成的 Markdown 表格原样输出（字段：排名🥇🥈🥉、笔记信息〔标题链接+作者+粉丝〕、互动数/点赞/评论/收藏/分享〔累计+↑新增双行〕）。数据 >20 条时附「查看更多」提示；用户说「查看更多」→ `notes(offset=20)` 续读，HTML 用 `top=50` 重生成。

**② 📊 七日热门笔记分析（Top{条数}）**——由你撰写 3 个模块，全部基于获取的数据，从创作者视角给可执行建议：
- **💡 热门内容分析**：封面设计/内容创作/内容价值/热点结合四类特征 + 实际效果 + 参考笔记链接
- **📈 爆款标题分析**：提问式/数字式/情绪词/利益点四类（标题特征、模版、发布规律、参考标题）
- **✨ 最高数据作品分析**：最高点赞/收藏/评论/互动四个维度（风格、特征、数据效果、建议）

**③ 功能询问**（分析后立即展示，禁止跳过）：
```
技能还支持以下功能：
1️⃣ 订阅每日 19:30 推送七日爆款 TOP50（用 dsh 定时任务实现，创建前先跟用户确认）。
2️⃣ 生成小红书风 HTML 文件包（xhs_weekly action="html"，支持导出 PDF/图片）。
```

### HTML 生成

`xhs_weekly(action="html", top=20 或 50)` —— **从已入库榜单读取，禁止再次调 API**；小红书红风格（TOP3 奖牌、累计+↑新增双行、700px 卡片流），支持导出图片和 PDF。表格与 HTML 同数据同排序，排名完全一致。

## 错误处理

| 情况 | 处理方式 |
|------|---------|
| 未配置 RedFox API Key | 引导到面板「小红书七日爆款雷达 → 设置」填写 |
| 关键词未命中分类 | 展示推荐（1~3 个）等待确认，禁止直接查 |
| 数据 < 10 条 | 工具会提示；如实告知并建议换日期/分类 |
| 空数据 | 如实说明，不编造条目 |
| 积分不足（3201） | 提示充值地址 |

## 注意事项

- 数值全部来自接口返回，**严禁估算或编造**；分享字段用 `anaAdd.useShareCount`/`addShareCount`
- **禁止折叠输出**；**除 HTML 文件包外禁止输出任何其他文件**（CSV/JSON/TXT 等）
- `anaAdd` 里的 `addInteractiveount`/`addCollectedCunt` 是上游 API 的真实字段名（拼写如此），工具已正确映射
- 订阅推送用 dsh 定时任务（schedule_create，target 建议 new_once）实现，创建前先跟用户确认频率

## 在 DSH 插件里使用

- `xhs_weekly` 工具负责分类匹配/榜单查询/HTML 报告；七日分析 3 模块与三步输出由你完成
- `history` 列出榜单（新→旧）；对旧榜单补 HTML/读条目传 `boardId`
- 面板可直选分类查榜/看卡片/查看更多/生成 HTML；与对话流程共用同一份数据
